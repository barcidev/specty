# Reglas de Tarea: Interfaz de Usuario (UI)

- Diseña componentes accesibles (semántica HTML, etiquetas ARIA, navegación por teclado).
- Implementa estados de carga, vacío y error en cada vista.
- Respeta la jerarquía visual y tokens del sistema de diseño.
- Evita llamadas directas a base de datos desde componentes de UI.
