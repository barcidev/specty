# Reglas de Tarea: Pruebas y Aseguramiento

- Diseña pruebas siguiendo la estructura AAA (Arrange, Act, Assert).
- Aísla dependencias externas (red, base de datos) usando dobles de prueba (mocks/stubs) en pruebas unitarias.
- Cubre casos borde (entradas nulas, errores de red, límites numéricos).
- Evita pruebas frágiles acopladas a detalles de implementación interna.
