# Reglas de Tarea: Seguridad y Auditoría

- NUNCA confirmes secretos, credenciales o tokens en control de versiones.
- Valida la autorización de usuarios en el backend para cada recurso sensible.
- Aplica principios de mínimo privilegio en consultas y permisos de base de datos.
- Previene vulnerabilidades OWASP Top 10 (inyecciones SQL, XSS, CSRF).
