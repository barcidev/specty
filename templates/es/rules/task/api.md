# Reglas de Tarea: Lógica de Negocio y APIs

- Valida y desinfecta toda entrada en el borde de la API (DTOs).
- Usa códigos de estado HTTP semánticos (200, 201, 400, 401, 403, 404, 500).
- Mantén la lógica de negocio desacoplada de los controladores de transporte.
- Implementa paginación en listas y colecciones de datos.
