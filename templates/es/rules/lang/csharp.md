# Reglas de Tecnología: C# / .NET

- Usa tipos anulables explícitos (`<Nullable>enable</Nullable>`).
- Sigue las convenciones de nomenclatura de C# (PascalCase para clases/métodos, camelCase para campos privados o `_camelCase`).
- Usa inyección de dependencias para todos los servicios de aplicación.
- Ejecuta `dotnet format` para validar consistencia de estilo.
