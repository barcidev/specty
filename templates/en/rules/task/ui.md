# Task Rules: User Interface (UI)

- Ensure accessible components (semantic markup, ARIA labels, keyboard navigability).
- Always handle loading, empty, and error view states explicitly.
- Adhere to design system tokens and visual hierarchy.
- Avoid using raw Unicode glyphs or emojis as UI icons; use production-grade vector icon libraries (Lucide, Heroicons, Tabler, Phosphor, etc.) or clean inline SVGs.
- Prohibit direct database access from frontend UI components.
